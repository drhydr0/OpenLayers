# Feedback round 1 phone test

About 10 minutes. Install the newest `layers-dev.apk` over the current one.

1. **Select button.** The bottom bar reads Add, Select, Layers. Tap **Select**: the area selection sheet opens.
2. **Select several.** Tap **Layers**: **Select several** is at the top of the panel. Tap it, then tap two layers on the canvas: both are selected.
3. **Long press.** With Select several off, long-press a layer on the canvas: the phone buzzes, Select several turns on, and that layer is added. Long-press another layer: Select several turns off and only that layer is selected. The same works on rows in the layers panel.
4. **Default outline.** **Add → Shape → Rectangle**: it has a thin black outline.
5. **Free transform.** Select the rectangle. Drag a corner circle: width and height change independently and the opposite corner stays put. Drag a side square: only that side moves. The outline stays the same thickness. Try the same on an image and on a sticker. Pinch still scales evenly.
6. **Edit and opacity.** Select the rectangle and tap **Edit**: the sheet sits on the lower half, see-through, and the canvas isn't darkened. Change the fill color: the rectangle changes as you tap. Drag **Opacity**: it fades live. Tap **Cancel**: it goes back. Tap a slider heading (with ✎) and type an exact value.
7. **Fonts.** Select text, **Edit**, open the font list: each name is shown in its own font. Pick Lobster, then Bebas Neue: the canvas text changes live.
8. **Drag into a group.** Make a group, open it in the layers panel (folder icon). Drag a top-level layer's handle to just under the group's row: it joins the group without moving on the canvas. Drag a child to the very top of the list: it leaves the group, again without moving.
9. **Remove one from a group.** Double-tap a group, select one child, **Actions → Remove from group**: only that one leaves; the rest stay grouped.
10. **Space evenly.** Select three shapes at uneven spacing, **Actions → Space evenly → Across**: the outer two stay, the middle one moves so the gaps match.
11. **Nudge.** Select a layer, **Actions → Nudge**: only the canvas and arrows show. Tap the arrows and watch it move; switch the step to 10 px; tap **Done**. One **Undo** puts it back.
12. **200% export.** Export a PNG at 200%, then **Open image** with that file and export it again at 200%. If the phone has the memory free, 200% is offered.
