# Feedback round 2 phone test

About 6 minutes. Install the newest `layers-dev.apk` over the current one.

1. **No title bar.** The project list and the editor start right at the top of the screen; there is no grey "Layers" bar. Diagnostics shows its own heading.
2. **Two-finger navigation.** In the editor, tap empty canvas to clear the selection. Put two fingers anywhere and pinch and drag: the view zooms and pans; no layer moves. The hand button is gone.
3. Select a layer, put two fingers on it, and pinch and twist: the layer scales and turns. Then put two fingers on empty canvas with the layer still selected: the view moves, not the layer.
4. **Select area** and, while drawing, use two fingers: the view moves.
5. **Remembered text style.** Add text, pick a font, color, outline, and size, tap **Done**. Add another text: it starts with the same settings. Swipe the app away, reopen, open any project, add text: still the same settings.
6. **Select several.** Open **Layers**: the button sits above the list, and the top row is fully visible and tappable.
7. **Full history.** Make three edits, tap **Undo** twice and **Redo** once. Open **⋮ → History**: it lists all of them, newest first, including "Undo …" and "Redo …".
8. Tap an older entry: the canvas goes back to that point. Open History again: a "Go back to: …" entry is on top. Tap **Undo**: you return to where you were.
9. Undo once, then make a new edit (redo is now unavailable). Open History and tap the entry before the new edit: the undone change comes back.
