# Milestone 7 phone test

This one measures rather than checks features. It takes about 10 minutes. Install the newest `layers-dev.apk` from the `dev` release over the current one.

Please send back the diagnostics report from step 6 and the times you see; they are the capacity record for the first release.

## Create the heavy project

1. Open **Diagnostics** and tap **Make test project**. After some seconds a message gives the time it took; note it.
2. Go back to the project list and open **Large test project**. Note roughly how long it takes to appear.

## Feel

3. Drag a layer, pinch a layer, and pan and zoom with the hand button. Note whether each feels smooth, a little slow, or stuck.
4. Tap **Layers** and scroll the list from top to bottom. Expand one of the "Sticker" groups.
5. Tap **Undo** twenty times quickly, then **Redo** twenty times. Open **⋮ → History** and jump far back, then back to the top.

## Memory

6. Go back to the project list, open **Diagnostics**, and tap **Share**. Send the report: it has memory, storage, layer count, and history size.

## Export

7. In the large project, export a PNG at 100%. Note the time and that it succeeds.
8. Export at 200%. Note whether it succeeds, is refused as too large, or fails.
9. Open the exported image in Photos and compare it with the canvas.

## Survive a restart

10. Make one edit, wait for "Saved", swipe the app away, and reopen the project. The edit is there and Undo still reaches the earlier steps.

When done, you can delete the test project from the project list.
